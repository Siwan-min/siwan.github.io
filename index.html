    작가의 말

    안정적으로 운영될 수 있는 구조를 고민합니다

    저는 단순히 기능을 구현하는 것보다 서비스가 안정적으로 운영될 수 있는 구조를 고민하는 백엔드 개발자입니다. 개발 과정에서는 "어떻게 만들 것인가"보다 "왜 이런 구조가 필요한가"를 먼저 고민하며, 장애가 발생하더라도 빠르게 원인을 파악하고 재발을 방지할 수 있는 시스템을 만드는 것을 중요하게 생각합니다.

    현재는 삼성카드 통합 플랫폼 '모니모'에서 백엔드 개발을 담당하며 MSA 기반 서비스 API 설계, Redis 캐시 아키텍처 개선, 대량 데이터 Batch 처리, 제휴 플랫폼 구축 등의 업무를 수행하고 있습니다. 특히 여러 외부 서비스가 공통으로 사용할 수 있는 제휴 플랫폼을 설계하며 인증, 회원가입, 데이터 전달 구조를 공통화해 신규 제휴 서비스가 빠르게 연동될 수 있는 기반을 구축했습니다. 또한 Git Repository 통합과 Branch 전략을 재정립하여 배포 시간을 약 30분에서 5분으로 단축하고 운영 안정성을 높인 경험이 있습니다.

    이전에는 대규모 트래픽 기반 광고 플랫폼에서 외부 API 연동과 Batch 시스템을 개발하며 대량 데이터 처리 경험을 쌓았고, 반도체 제조 공정에서는 실시간 장비 제어 시스템과 공정 모니터링 시스템을 개발하며 안정성과 정확성이 중요한 시스템 개발을 경험했습니다. 서로 다른 도메인을 경험했지만 공통적으로 서비스의 안정성과 성능을 높이기 위한 구조를 고민하며 개발해왔습니다.

    앞으로도 변화하는 요구사항에 유연하게 대응하면서도 안정성과 확장성을 갖춘 플랫폼을 설계하는 백엔드 엔지니어로 성장하고 싶습니다. 다양한 사용자가 신뢰하고 사용할 수 있는 서비스를 만들기 위해 기술적인 완성도를 높이고, 팀과 함께 더 나은 구조를 만들어가는 개발자가 되고자 합니다.
