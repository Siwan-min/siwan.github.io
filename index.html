    작가의 말

    문제의 원인을 구조적인 흐름에서 찾습니다

    저는 문제의 원인을 단순 현상이 아닌 구조적인 흐름에서 찾으려고 하는 백엔드 개발자입니다. 기능 구현 자체보다 실제 운영 환경에서 얼마나 안정적으로 동작하는지, 장애가 발생했을 때 어떤 영향이 발생할 수 있는지를 항상 함께 고민하며 개발해왔습니다.

    현재는 삼성카드 통합 금융 플랫폼 '모니모' 프로젝트에서 금융 및 제휴 서비스 서버 개발과 운영을 담당하고 있습니다. 금융 서비스 특성상 데이터 정합성과 안정성이 매우 중요하기 때문에, 단순 API 개발뿐 아니라 트랜잭션 처리, 대량 데이터 배치 구조, Redis 기반 캐시 아키텍처 개선, 제휴사 연동 구조 설계 등 운영 환경 중심의 개발 경험을 쌓아왔습니다. 특히 실제 서비스 운영 과정에서 발생한 DB 부하나 응답 지연 문제를 개선하기 위해 배치 처리 구조를 Chunk 기반으로 변경하거나, 마이데이터 API 호출 구조를 병렬 처리 방식으로 개선하여 응답 속도를 단축한 경험이 있습니다.

    또한 최근에는 제휴 플랫폼 관련 업무를 수행하며 외부 제휴사 로그인 및 회원가입 연동, 인증 토큰 기반 보안 구조, 고객 데이터 전달 프로세스 등을 설계했습니다. 여러 제휴사가 함께 연결되는 구조이다 보니 단순 기능 개발보다 확장성과 운영 안정성을 함께 고려해야 했고, 이를 통해 시스템 전체 흐름을 바라보는 시야를 키울 수 있었습니다.

    이전에는 광고 플랫폼 회사에서 대규모 트래픽 기반 광고 플랫폼 서버를 개발하며 Redis, EhCache 기반 캐시 구조와 배치 처리 시스템을 운영한 경험이 있습니다. 또 반도체 장비 회사에서는 C++, C# 기반 장비 제어 시스템 개발 업무를 담당하며 RS-232 기반 실시간 데이터 처리, 센서 데이터 수집, PID 제어 알고리즘 적용 등을 경험했습니다.

    저는 장애가 발생했을 때 단순히 빠르게 처리하는 것보다 왜 문제가 발생했는지를 끝까지 분석하고, 같은 문제가 반복되지 않도록 구조적으로 개선하는 것을 중요하게 생각합니다. 앞으로도 안정성과 확장성을 함께 고려하며 실제 운영 환경에 강한 시스템을 설계할 수 있는 백엔드 개발자로 성장하고 싶습니다.
